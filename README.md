# MJAPANI SESSION

Tovuti ndogo ya kutengeneza SESSION ID ya WhatsApp bot — kwa QR au Pairing Code.

## Jinsi inavyofanya kazi
1. Mtumiaji anafungua tovuti, anachagua QR au Namba ya Simu.
2. Anaunganisha WhatsApp yake (muda mfupi, kipindi cha hapa tu, si cha kudumu).
3. Mara moja baada ya kuunganika, SESSION ID (herufi ndefu zinazoanza na `MJAPANI~`) zinaonekana juu ya skrini, tayari ku-copy.
4. Session ya muda (temp) inafutwa seva-ni mara moja baada ya SESSION ID kutolewa — huwezi kurudi kuitazama tena, kwa hiyo ihifadhi mara moja.

## Kutumia SESSION ID
Bandika kwenye Railway Variable `SESSION_ID` ya **MJAPANI BOT** yako kuu. Bot kuu itasoma hiyo variable na kuanza moja kwa moja bila pairing wala Volume.

## Railway Deploy
1. Pakia faili hizi kwenye GitHub repo mpya (tofauti na repo ya MJAPANI BOT).
2. Railway → New → GitHub Repo → chagua hii repo.
3. Hakuna Variable ya lazima.
4. Settings → Networking → Generate Domain (ili upate link ya umma ya tovuti).
5. Fungua link hiyo, jaribu QR au Pairing Code.

## Onyo la usalama
- SESSION ID ni sawa na nywila ya WhatsApp yako. Usimtumie mtu asiyemwamini.
- Tovuti hii ni ya matumizi yako binafsi — usiishiriki hadharani bila password, vinginevyo yeyote anaweza kujaribu kuunganisha namba yake mwenyewe (haiwezi kuiba akaunti ya mtu mwingine moja kwa moja, lakini bado ni vizuri kuilinda).
